## ✨ Features

- **Responsive single-page application** — clean layout that adapts across devices
- **Home & Hero section** — personal introduction and professional summary
- **Experience section** — timeline of professional and project experience
- **Projects & Highlights** — dedicated cards for notable work including:
  - FIRST Stronghold 2016 — Home page of VFL
  - FIRST Steamworks 2017 — Capstone Project
  - Autonomous Vehicle Path Planning — Capstone Project
  - The Beat Revival Project — User-generated time trials and more
- **Resume download** — one-click access to my current resume
- **Font Awesome icons** — integrated via Kit for crisp, scalable iconography
